**Real-Time Localization for Autonomous EV Charging Rover**

Developed at **EFI Automotive** (Lyon, France), Sept 2022 - Jan 2023.

### Highlights

- Developed a **real-time localization system** using Python, combining **ML models and OpenCV-based template matching** for high-precision visual navigation
- Built an **end-to-end data engineering pipeline**: on-field data collection (100+ samples), structured storage, preprocessing, augmentation, and automated dataset versioning
- Implemented **full MLOps workflows** using Git, Docker, and CI/CD (GitHub Actions)

### Tech Stack

Python, OpenCV, Docker, GitHub Actions, CI/CD
